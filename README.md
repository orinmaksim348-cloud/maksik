# 🚀 Сайт для Детского Развлекательного Центра «МАКСИК» (г. Шахты)

Готовый современный интерактивный сайт-лендинг для продажи клиенту из группы ВКонтакте: [vk.com/club241220922](https://vk.com/club241220922).

---

## 📁 Структура проекта:
- **`index.html`** — Главная страница с продающей структурой, калькулятором, лентой событий и модальными окнами.
- **`styles.css`** — Премиальные стили, яркие градиенты, анимации, стекломорфизм и мобильная адаптивность.
- **`app.js`** — Логика: калькулятор сметы, система бронирования, личный кабинет («Макси-Клуб»), лента новостей, лайки, фильтры.
- **`assets/`** — Реальные материалы из группы ВКонтакте (официальный баннер `cover.jpg` и логотип `logo.jpg`).
- **`Коммерческое_предложение_Максик.txt`** — Готовый скрипт для переписки в WhatsApp и звонка владельцу центра.

---

## 🎯 Реализованный функционал:
1. **Современный сочный дизайн**: Разработан с учётом детской развлекательной ниши (яркие, но аккуратные акценты, дружелюбная типографика, плавающие элементы, карточки аттракционов).
2. **Интерактивные аттракционы**: Лазертаг, приставки PS5 & Xbox, сенсорный живой пол, косогор/скалодром, «Оживи рисунок», умная песочница, батуты и банкетные комнаты.
3. **Пакеты «День Рождения под ключ»**: 3 проработанных тарифа («Мини-Старт», «Макси-Драйв», «Всё включено VIP») с полным списком опций.
4. **Умный калькулятор & Онлайн-бронь**:
   - Автоматический пересчёт стоимости в зависимости от пакета, количества детей и доп. шоу (бумажное шоу, фотограф, торт, мастер-классы).
   - Генерация красивого электронного билета с номером брони и кодом для кассы.
   - Быстрая отправка параметров брони прямо в WhatsApp администратору.
5. **Главная лента событий и мероприятий**:
   - Реальные анонсы из группы: «Ёлки 2027: Новогодний поезд» (1 700 ₽), «Пижамная вечеринка», конкурсы, скидки по средам.
   - Фильтрация по рубрикам («Афиша», «Мастер-классы», «Новости», «Акции»).
   - Интерактивные лайки с сохранением.
   - Кнопка бронирования билетов прямо из карточки события.
   - Форма добавления новых событий для владельца сайта.
6. **Программа лояльности «Макси-Клуб» & Личный кабинет**:
   - Быстрая регистрация с начислением 500 приветственных бонусов.
   - Виртуальная карта гостя с номером и балансом.
   - История бронирований.

## 🚀 Запуск и хостинг:

### 1. Веб-сайт (GitHub Pages):
Сайт автоматически опубликован и работает онлайн:
- **Живой сайт:** `https://orinmaksim348-cloud.github.io/maksik/`

### 2. Telegram Бот 24/7 (@maksikauth_bot):
Для круглосуточной работы бота без включенного компьютера:
- **Бесплатный хостинг Render.com (Рекомендуется):**
  1. Зарегистрируйтесь на [render.com](https://render.com) через ваш GitHub.
  2. Нажмите **New +** -> **Web Service** и выберите репозиторий `maksik`.
  3. Render автоматически определит настройки (`package.json` и `render.yaml`).
  4. Нажмите **Deploy** — бот запустится в облаке и будет работать 24/7!
- **Локальный запуск на компьютере:**
  ```bash
  npm start
  # или
  node telegram_bot/bot.js
  ```
