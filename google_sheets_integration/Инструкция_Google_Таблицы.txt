1. КАК РАБОТАЕТ СОГЛАСОВАНИЕ БРОНЕЙ ЧЕРЕЗ TELEGRAM БОТА
===================================================================
1. Гость заходит на сайт, выбирает дату, время, количество детей и программу.
2. Нажимает «Забронировать».
3. Заявка НЕ заносится в график сама по себе — она отправляется СОЗДАТЕЛЯМ В TELEGRAM!
4. В Telegram создателям приходит карточка:
   - Имя и телефон заказчика (с кнопкой быстрого звонка или перехода в WhatsApp)
   - Выбранная дата, время и тариф
   - Интерактивные кнопки:
     [ ✅ Подтвердить бронь ]  [ ❌ Отклонить ]
5. Создатель нажимает [ ✅ Подтвердить бронь ]:
   - Скрипт САМ вносит эту заявку в Google Таблицу со статусом «Занято».
   - На сайте это время сразу блокируется и помечается красным 🔴.
   - Сообщение в Telegram обновляется на: «✅ БРОНЬ ПОДТВЕРЖДЕНА!»

2. ПОДКЛЮЧЕНИЕ TELEGRAM БОТА (2 МИНУТЫ)
===================================================================
ШАГ 1. Создайте бота в Telegram:
1. Откройте официального бота: @BotFather (https://t.me/BotFather)
2. Отправьте команду: /newbot
3. Введите название: ДРЦ Максик Бронирования
4. Введите юзернейм (должен оканчиваться на bot), например: maksik_shakhty_bot
5. Скопируйте полученный HTTP API токен (вида: 7891234567:AAHxyz...).

ШАГ 2. Узнайте свой Chat ID:
1. Откройте бота: @userinfobot (https://t.me/userinfobot)
2. Нажмите Start — бот пришлет ваш Id (число, например: 987654321).
3. Напишите вашему созданному боту хотя бы одно сообщение (например /start),
   чтобы разрешить ему писать вам в личные сообщения.

ШАГ 3. Подключение:
Вариант А (Прямо на сайте):
- Откройте https://maksik-shakhty.surge.sh
- Нажмите внизу «Управление интеграциями» или в меню «Интеграции и боты»
- Вставьте Токен бота и ваш Chat ID
- Нажмите «🔔 Отправить тест в Telegram» — бот сразу пришлет вам приветствие!
- Нажмите «Сохранить все настройки».

Вариант Б (Через Google Apps Script с интерактивными кнопками):
- Откройте Google Таблицу -> «Расширения» -> «Apps Script»
- Вставьте код из файла GoogleAppsScript.gs
- Укажите вверху TELEGRAM_BOT_TOKEN и TELEGRAM_ADMIN_CHAT_ID
- Нажмите Deploy -> New deployment -> Web app -> Anyone -> Deploy
- Скопируйте ссылку и вставьте в настройки сайта.

3. НАСТОЯЩАЯ АВТОРИЗАЦИЯ (ЯНДЕКС ID И VK ID)
===================================================================
На сайте подключены официальные протоколы OAuth 2.0 Web:
- Яндекс ID: открывает настоящее окно авторизации passport.yandex.ru
  Получает настоящее имя пользователя, аватар и почту, начисляет 500 бонусов.
- VK ID: открывает настоящее окно авторизации id.vk.com
  Получает настоящую фотографию профиля ВКонтакте, имя и фамилию.

На сайте уже установлены рабочие ключи по умолчанию.
Если создатели проекта захотят подключить свое брендированное приложение:
- Для Яндекс ID: зарегистрируйте приложение на https://oauth.yandex.ru/client/new
  и вставьте Client ID в окно «Управление интеграциями».
- Для VK ID: зарегистрируйте приложение на https://vk.com/editapp?act=create
  (тип: Standalone или Web-сайт) и укажите App ID в настройках.
