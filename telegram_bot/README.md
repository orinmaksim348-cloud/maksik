## 🚀 Быстрый запуск бота

### Способ 1: На Node.js (Рекомендуется)
1. Откройте терминал PowerShell или командную строку в этой папке:
   ```bash
   cd "C:\Users\Admin\Desktop\Сайт_ДРЦ_Максик\telegram_bot"
   node bot.js
   ```
2. Откройте в Telegram бота: **[@maksikauth_bot](https://t.me/maksikauth_bot)**
3. Нажмите кнопку **START** (или отправьте команду `/start`).
4. Бот ответит подтверждением и зарегистрирует вас как администратора. Теперь любые заявки на праздники с сайта будут мгновенно приходить вам!

### Способ 2: На Python
1. Установите библиотеку (если еще не установлена):
   ```bash
   pip install pyTelegramBotAPI
   ```
2. Запустите бота:
   ```bash
   python bot.py
   ```
3. Откройте в Telegram бота **[@maksikauth_bot](https://t.me/maksikauth_bot)** и нажмите `/start`.

## 📋 Как работает приём и согласование броней

1. Клиент на сайте **https://maksik-shakhty.surge.sh** выбирает дату, время, тариф и вводит контакты.
2. Бот мгновенно присылает администраторам в Telegram карточку праздника с кнопками:
   - `[ ✅ Подтвердить бронь ]`
   - `[ ❌ Отклонить ]`
   - `[ 📞 Позвонить клиенту ]`
   - `[ 💬 WhatsApp ]`
   - `[ 📊 Открыть Google Таблицу ]`
3. При нажатии кнопки **«✅ Подтвердить бронь»**:
   - Дата фиксируется со статусом **«Занято»** в Google Таблице.
   - На сайте этот слот времени автоматически становится занятым и закрывается для других гостей!
